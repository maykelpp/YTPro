YTPro — modo 100 % local

El servidor NanoHTTPD, yt-dlp y FFmpeg se ejecutan dentro del teléfono.
No requiere PC, Termux ni servidor remoto para funcionar. Internet sí es
necesario para buscar y descargar contenido.

Lee ARQUITECTURA_LOCAL.md para conocer la compatibilidad real de cada plataforma
y las limitaciones de TikTok en esta integración Android.

Compilación: GitHub Actions > Build APK > Artifacts > YTPro-apk.
